Які поля у формі додання рецепту?

Зараз є: назва, інгредієнти, кроки, час. Reference.html показує КБЖУ.

// new_recipe
name
Борщ
ingredients
буряк, картопля...
steps
варити буряк 40 хв...
cook_time_min
45
[ save_recipe ]

A — Базові 4 поля

name · ingredients · steps · cook_time. Просто і швидко, без зайвого.

// new_recipe
name
Борщ

буряк, картопля...

варити буряк 40 хв...
time
45
ккал
320
білки
12г
[ save_recipe ]

B — + КБЖУ поля

Додаємо ккал, білки, жири, вуглеводи. Як у reference.html — відображаються у картці рецепту.
