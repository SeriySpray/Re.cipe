Як відображати рецепти у правій панелі?

Що відбувається при кліку на рецепт — теж залежить від варіанту.

// recipes (3)
Борщ
45 хв
320 ккал
Піца
90 хв
580 ккал
Салат
15 хв
— ккал
клік → модальне вікно з деталями

A — Сітка карток

2 колонки, компактно. Клік відкриває модальне вікно поверх layout-у з повним рецептом.

// recipes (3)
Борщ
буряк, картопля, м'ясо...
кроки: варити буряк 40 хв...
45 хв
Піца
тісто, соус...
90 хв
клік → розгортається в місці

B — Список з розгортанням

Компактні рядки, активний рецепт розгортається inline. Деталі видно без переходів.

// list
Борщ
Піца
Салат
// detail
Борщ
буряк · картопля · м'ясо
варити буряк 40 хв, додати картоплю...
45 хв
320 кк
права панель ділиться: список | деталь

C — Master-Detail

Права панель поділена: список зліва, деталі справа. Все видно одночасно без модалів.
